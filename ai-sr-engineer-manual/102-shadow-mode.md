# 102. Shadow mode (ship without deciding)

Before a model owns a decision, run it next to the old process:

- Product still uses rules / previous model
- New model scores are logged, not shown, or shown as "advisory"
- Next week: compare what it would have done vs what happened
- Then canary (chapter 80)

This is how you look senior in a bank or telco. Capstone A can pretend:
write scores to CSV for a week (`43_batch_score`) without calling anyone.
